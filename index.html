Upload JSON Schedule

Your file must be valid JSON matching this structure:

{
  "title": "TODAY'S SCHEDULE",
  "items": [
    { "time": "7:00 AM", "description": "Wake up & stretch" },
    { "time": "9A", "description": "Deep work block" },
    { "time": "14", "description": "Lunch" }
  ]
}
  • items is required and must be a non-empty array.
  • Each item needs time and description (or desc) as text.
  • time accepts formats like 7:00 AM, 9A, 1P, or 14 — it gets auto-formatted.
  • title is optional; if present, it fills the title field.
